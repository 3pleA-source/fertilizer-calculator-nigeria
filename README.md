# fertilizer-calculator-nigeria
A simple fertilizer calculator for Nigerian smallholder farmers
This project helps smallholder farmers calculate exact fertilizer needed.
Solve problems of bag size variation and price variation by location.
Built with python.

Feature:
-Supports different crops: maize, rice cassava, yam.
-Farmers enters farm size in acres
-Farmer enters local bag size and price
-Calculate kg needed, bags needed, and total cost

Future plan: This is Phase 1 of a bigger AgricTech platform (Seed, Calculator, Pest Alert, Weather, Market Price and many more)
